📦 설정 이동 이 설치본의 서버 설정을 파일로

서버 목록·계정·비밀번호·OTP Secret·로그인 단계를 JSON 한 파일로 옮깁니다. 이 빌드에 기본 서버가 들어 있지 않을 때 설정을 받아오는 방법입니다. 파일에는 비밀번호와 OTP Secret이 그대로 들어갑니다 — 비공개로 전달하세요.

🔐 사이트 접근 권한 어느 주소에서 동작할지

확장 프로그램은 설정된 서버 주소에만 접근합니다. 주소를 추가하거나 바꾼 뒤에는 한 번 허용해 주세요. 허용 전에는 그 주소에서 자동 로그인이 동작하지 않습니다.

⬆️ 업데이트 새 설치본이 나왔는지 어디서 보는지

공개 주소여야 합니다(설치본은 비공개 유지). 비워두면 확인하지 않습니다. 다른 서버에 두려면 그 서버가 CORS를 허용해야 합니다.

비공개 저장소 링크도 됩니다. 새 탭으로 열리므로 브라우저에 로그인된 계정으로 내려받습니다.

⚡ 입력 동작 모든 서버에 공통으로 적용됩니다

120ms

20ms(초고속) ~ 300ms(안정적). 네트워크 지연이 있거나 키 누락 시 간격을 늘려주세요.
