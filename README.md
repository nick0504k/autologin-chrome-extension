# 자동 로그인 & E2E 테스트 (Chrome 확장)

설정한 서버에 자동으로 로그인하고, 저장한 동작 플로우를 원클릭으로 실행하는
Manifest V3 크롬 확장 프로그램입니다. **어떤 사이트에도 묶여 있지 않습니다** —
주소·계정·로그인 절차는 전부 설정에서 읽습니다. 이 문서에 특정 서버의 주소나
계정이 나오지 않는 것은 그 때문입니다. 쓰는 서버가 무엇인지는 설정 화면이 알려줍니다.

## 무엇을 하나

- **자동 로그인**: ID/비밀번호 입력, 가상 보안 키패드 클릭 입력, 2차 인증 OTP(TOTP) 생성·입력
- **여러 페이지에 걸친 로그인**: 로그인 버튼 → 자격증명 → OTP처럼 페이지가 나뉘어 있어도,
  페이지마다 무엇을 알아보고 무엇을 할지 설정(`loginSteps`)으로 기술합니다
- **모바일 지갑 로그인**: 고객 선택 → 지갑 이동 → PIN 키패드 입력.
  어느 페이지에서 무엇을 누를지도 설정입니다
- **서버 여러 개**: 그룹 탭으로 묶고(드래그로 순서 변경), 서버마다 계정을 여러 개 두고 전환
- **E2E 녹화 & 실행**: 브라우저에서 한 동작을 기록해 시나리오로 저장하고 다시 실행
- **업데이트 알림**: 공개된 `version.json`을 하루 한 번 확인해 새 버전을 알려줍니다

## 설치

`chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드** →
이 폴더를 선택합니다. 이미 로드되어 있으면 카드의 **새로고침(⟳)** 을 누르세요.

Windows용 설치 마법사(`AWA_AutoLogin_Setup.bat`)와 macOS용(`.command`)이 함께 배포되는
빌드도 있습니다. 파일 하나를 실행하면 추출부터 Chrome 등록까지 진행합니다.

## 설정

서버가 들어 있지 않은 빌드는 서버 0개로 시작합니다. ⚙ 설정에서 직접 추가하거나,
**📥 설정 가져오기**로 다른 설치본에서 내보낸 JSON을 불러오세요.

설정 화면은 세 섹션입니다.

| 섹션 | 담는 것 |
|---|---|
| 🖥️ 서버 | 소속 그룹 · 대상 서버 · 이름/활성화 · 접속 주소 · 서버 환경 · 은행 · 서버 유형 |
| 👤 계정 | 로그인 계정 ID · 비밀번호 (모바일이면 고객 선택) |
| 🔑 로그인 방식 | 비밀번호 입력 방식 · 2차 인증 OTP Secret |

- **접속 주소**: 한 줄에 하나. 첫 줄이 기본 주소이고 **경로·쿼리까지 저장**됩니다.
  저장한 쿼리가 모두 들어 있으면, 페이지가 쿼리를 더 달고 있어도 같은 주소로 인식합니다.
  로그인이 여러 호스트에 걸쳐 있으면 줄을 추가하세요 — 둘째 줄부터는 호스트만 씁니다.
- **사이트 접근 권한**: 확장 프로그램은 manifest에 어떤 사이트도 선언하지 않습니다.
  설정한 주소에 대해서만 권한을 요청하므로, 서버를 추가한 뒤 **사이트 접근 허용**을 눌러주세요.
  허용 전에는 그 주소에서 자동 로그인이 동작하지 않습니다.
- **로그인 단계** (`loginSteps`): 페이지마다 `find`(버튼 문구 또는 셀렉터)로 알아보고
  `click` / `credentials` / `otp` 중 하나를 수행합니다. 코드가 아는 동작은 그 셋뿐이고,
  어떤 버튼을 누를지·어떤 칸에 넣을지는 설정이 정합니다.
- **OTP**: Base32 Secret을 넣으면 RFC 6238 TOTP 6자리를 브라우저 안에서 계산해 입력합니다.
- **🔍 자동 감지**: 한 주소를 여러 서버가 공유할 때 어느 서버인지 API 응답으로 가립니다.
  식별용 엔드포인트가 설정된 빌드에서만 보입니다.

### 설정 내보내기 / 가져오기

⚙ 설정 → **동작 및 속도 설정** → `📤 설정 내보내기` / `📥 설정 가져오기`.

- 내보내기: 서버 목록·계정·비밀번호·OTP Secret·로그인 단계를 JSON 한 파일로 저장합니다.
  모바일 서버의 고객 목록 주소·선택 페이지·기본 사용자도 함께 나갑니다.
  **비밀번호와 OTP Secret이 평문으로 들어가므로 비공개로 전달하세요.**
- 가져오기: 같은 키의 서버는 파일 내용으로 덮어쓰고, 파일에 없는 서버는 그대로 둡니다
  (합치기이지 교체가 아닙니다). 가져온 뒤 새 주소에 **사이트 접근 허용**을 한 번 눌러주세요.

## 팝업

- 탭 줄: `🔑 자동 로그인` / `🎬 E2E 녹화 & 실행`. 각 탭 안에 그 탭의 컨트롤이 들어 있습니다 —
  자동 로그인 탭의 **스위치**(전체 켜기/끄기)와 E2E 탭의 **● 기록 버튼**. 어느 화면에 있든
  누를 수 있고, 누르는 것만으로 화면이 바뀌지는 않습니다.
- 그룹 칩: 넘치면 **눌러서 끌어** 옆으로 넘깁니다. 끌어 넘긴 것은 클릭으로 치지 않습니다.
- 서버별 **↗** 는 새 탭으로 열고, **⚙** 는 그 서버의 설정 폼을 바로 엽니다.
- 하단 **로그인 버튼**은 목록이 길어도 화면에 붙어 있습니다.

## ID별 자동 로그인 비밀번호

- 팝업에서 서버와 계정 ID를 선택하고 비밀번호를 수정한 뒤 **저장**하세요.
- 같은 서버의 각 ID에 별도 비밀번호가 저장됩니다. ID를 바꾸면 저장된 비밀번호도 함께 바뀝니다.
- 이 설정은 확장 프로그램이 입력하는 값을 저장할 뿐, 사이트의 실제 계정 비밀번호를 바꾸지 않습니다.

## 서버별 자동 로그인 켜기/끄기

- 서버 목록의 스위치로 서버별로 끕니다. 끈 서버에서는 아무것도 입력하지 않습니다.
- 수동 작업이 필요하면 해당 서버를 **OFF**로 끈 뒤 같은 줄의 **↗** 로 접속하세요.
- 탭 줄의 스위치는 전체를 한 번에 끕니다.

## 전체 데이터 삭제 (Format)

⚙ 설정 맨 아래 **🧨 전체 데이터 삭제 (Format)**. 두 번 확인한 뒤 지웁니다.

- 지우는 것: 서버 설정·계정·비밀번호·OTP Secret, 녹화한 E2E 시나리오, 허용한 사이트 접근 권한,
  업데이트 상태 등 `chrome.storage.local`에 저장된 전부.
- **되돌릴 수 없습니다.** 필요하면 먼저 `📤 설정 내보내기`로 받아두세요.
- 지운 뒤에는 빌드가 함께 배포한 설정이 다시 올라옵니다 — 설치 직후 상태입니다.

옆의 **설정만 기본값으로**와 다릅니다: 그쪽은 서버와 전역 설정만 되돌리고,
녹화한 시나리오와 허용한 권한은 그대로 둡니다.

## 업데이트 알림

언패키지(load unpacked) 설치라서 크롬이 자동 업데이트하지 못합니다. 대신 **버전만 공개**해 두고
새 설치본이 나왔는지 알려줍니다.

- 하루 한 번 `version.json`을 읽어, 설치된 버전보다 높으면 아이콘에 **NEW** 배지를 띄우고
  팝업 상단에 `🆕 새 버전 vX.Y.Z · 설치본 받기`를 보여줍니다.
- 버튼을 누르면 설치본 주소가 **새 탭**으로 열립니다. 비공개 저장소 링크를 써도 됩니다 —
  브라우저에 로그인된 계정으로 내려받기 때문입니다.
- 두 주소 모두 ⚙ 설정 → **동작 및 속도 설정**에서 바꿀 수 있습니다(재빌드 불필요).
- 확인 주소는 **공개**여야 하고, GitHub raw가 아닌 서버에 두면 그 서버가 CORS를 허용해야 합니다.

## 저장되는 것

설정은 `chrome.storage.local`에만 저장되며 어디로도 전송되지 않습니다.
내보내기 파일에는 **비밀번호와 OTP Secret이 평문으로** 들어가므로 전달에 주의하세요.

## 코드와 데이터

확장 프로그램의 **코드는 어떤 사이트도 알지 못합니다**. 호스트 주소, 계정, OTP Secret,
로그인 절차(버튼 문구·셀렉터·순서), 모바일 지갑의 페이지와 라벨은 전부 `config/servers.js`
한 파일에 있고, 그 파일은 비어 있어도 프로그램은 똑같이 동작합니다.

```js
globalThis.AwaShippedServers = { SERVERS: { … }, NEW_SERVER: { … }, SUPERAPP_PATH: "…", … };
```

서버가 하나도 없는 빌드는 팝업에 **등록된 서버가 없습니다** 안내와 설정 버튼만 보여줍니다.
설정은 `📥 설정 가져오기` 파일 하나로 받습니다.
